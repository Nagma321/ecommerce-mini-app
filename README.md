# E-Commerce Mini App

A full-stack e-commerce mini project built using React and Django REST Framework.

## Features
- Product listing from backend API
- Modern UI with animated background
- Add to Cart functionality
- Cart total calculation
- Responsive layout

## Tech Stack
Frontend:
- React
- HTML
- CSS
- JavaScript

Backend:
- Django
- Django REST Framework

## How to Run

Backend:
1. cd backend/server
2. python manage.py runserver

Frontend:
1. cd frontend
2. npm start

Open in browser after running frontend: http://localhost:3000
